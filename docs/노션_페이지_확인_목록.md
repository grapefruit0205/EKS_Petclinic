## 판정 기준

- **본문확인:** fetch 결과의 본문 끝까지 확인한 기록이 있다. 코드 실행·첨부 검증·내용의 기술적 정확성 보증은 아니다.
- **부분확인:** fetch는 성공했으나 응답이 잘려 본문 전체와 추가 하위 페이지 여부를 확정할 수 없다.
- **조회기록:** 이전 조회·요약은 남아 있지만 전체 응답을 재확인하지 못했다. 전체 완독으로 집계하지 않는다.
- **미확인:** URL/제목만 확보했거나 본문 조회 성공 증거가 없다.
- 원문 `Loading ... code`는 실제 코드가 아니다. 본문확인 상태여도 원문에 없는 코드·단계는 확인할 수 없다.
- SVG/HTML/이미지 첨부는 별도다. 설명·캡션만 읽은 것을 첨부 전체 검증으로 세지 않는다. 외부 참고 링크의 다른 트리 전체는 순회 대상에서 제외했다.

**범위:** 알려진 본문 페이지 185개 = 학습 DB row 143개 + Day 요약 10개 + EC2 하위 4개 + 루트·허브·준비·테스트 9개 + Docker 3일 자료모음 하위 19개. 아래 표에 185개를 각각 한 번씩 기재했고, **185개 모두 단일 조회로 닫는 `</content></page>` 본문 끝과 실제 child 여부까지 확인 완료**했다. 데이터베이스 4개와 datasource 스키마는 별도이며 본문 수에 중복 합산하지 않는다. 원문 자체의 `Loading ... code` 표시·생략 안내 및 미열람 첨부(SVG/HTML), 실제 명령 실행은 본문 끝 확인과 별개로 구분한다.
